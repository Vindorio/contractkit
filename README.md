# contractkit

> Ruby gem for aggregating federal procurement data from SAM.gov (contract
> opportunities) and USASpending.gov (award history). Pre-alpha; private repo
> while design and scaffolding stabilize.

## Status

This repository currently contains design docs and a backlog of pre-filed
issues. No gem code has been written yet.

- Domain knowledge: [`docs/domain/`](docs/domain/)
- Design decisions (data models, reliability, extraction plan, packaging):
  [`docs/design/`](docs/design/)
- Contributor guides: [`docs/contributing/`](docs/contributing/)
- v0.1.0 issue backlog: [`ISSUES.md`](ISSUES.md)

When the gem reaches a state where it can be used externally and the docs
are clean, this repo will be made public under MIT.
